# Report spec

- Audience: inference engineers, technical founders, and reviewers of the public SLO Router repository.
- Purpose: determine which additional experiments are required, execute reproducible experiments possible on the current harness, and state only claims supported by evidence.
- Scope: SLO-aware heterogeneous LLM routing, Jev feature extraction, queue/load behavior, cost-quality-latency evaluation, and failure handling.
- As of: 2026-09-23.
- Geography: global technical ecosystem; no market geography constraint.
- Required sections: research question, hypotheses, related evaluation standards, experimental system, methods, results, threats to validity, counter-review, release claims, next experiments, references.
- Citation style: inline Markdown links plus source registry.
- Output: Markdown in research/deep-study/final-report.md; compact experiment tables also surfaced in README.
- Tone: technical, skeptical, reproducible.
- Must include: raw artifact paths, repeated-trial aggregation, negative Jev result, baseline comparison, load and SLO sweeps.
- Must exclude: universal production-savings claims and simulated results presented as real-model benchmarks.
